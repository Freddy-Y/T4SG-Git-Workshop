1. What is the difference between git and GitHub?

ANSWER: Git is a version control software that lets programmers store and compare different versions of their code. GitHub is a cloud hosting software that enables Git.

2. Why is version control important?

ANSWER: Firstly, code doesn't always work the first time, so having version control helps you ensure that the only code that makes it to the final product is correct. Secondly, when multiple people are working on different parts of the same project, version control helps ensure that the two versions merge seamlessly.

3. What is the command to view a branch's commit history?

ANSWER: git log

4. What command lists all the branches in your local repository? Which one lists those in the remote?

ANSWER: git branch (and git branch -r for those in the remote repo)

5. To prevent specific files and folders from being commited to a repository, what should you do?

ANSWER: Put the names of those files and folder paths into the .gitignore file
